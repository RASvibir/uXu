## Finding This Manual From 0?0

1. On the root console, press **RTFM** (opens the 0?0 User Guide).
2. Click **INDEX ARCHIVE MANUALS** (or type `ARCHIVE MANUALS`).
3. Search by your archive name or manual title.

Declare manuals in `data.json` so 0?0 can find them:

```json
"uxu": {
  "manuals": [
    {
      "title": "Visitor Guide",
      "path": "manuals/USER-MANUAL.md",
      "description": "How to use this archive"
    }
  ]
}
```
