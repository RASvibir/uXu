# Starter — make your own archive

**Id:** `Starter.uXu.0003`  
**What it is:** the public practice room. Copy it. Don’t worry about breaking it — this folder is the teaching copy.

Personal rooms (like someone’s private archive) are separate. This one stays a template for everyone.

## The whole recipe

```text
archives/Your-Name/
  index.html              ← the page
  data.json               ← name, blurb, list of items
  README.md               ← short story
  manuals/USER-MANUAL.md  ← optional visitor guide
```

That’s enough for a first archive.

## Make yours in four steps

1. **Look here first** — on 0?0 type `OPEN STARTER` (or open this `index.html`).
2. **Copy this folder** → `archives/Your-Name/`  
   (or copy repo `/templates/` if you want a blank twin).
3. **Edit `data.json`** — `archiveName`, `description`, and `shows`.
4. **Open your `index.html`**, then ask to register: pull request, or email **rasip@chloreform.org**.

You’ll get an id like `Your_Name.uXu.NNNN`.

## Tips (written for a first project)

- Start tiny: one title, one sentence, one item.
- You can change everything later.
- Audio, fancy players, and iNi provenance are optional — add them only when you want.
- On 0?0, `CREATE ARCHIVE` reprints this recipe and the next free serial.
